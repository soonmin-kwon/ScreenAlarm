# Screen Alarm

귀여운 GIF를 화면 위에 띄워 두고 알람까지 남은 시간을 확인할 수 있는 Windows용
카운트다운 알람입니다.

[최신 버전 다운로드](https://github.com/soonmin-kwon/ScreenAlarm/releases/latest)

## 설치

1. Releases 페이지에서 `ScreenAlarm-win-x64`로 시작하는 최신 ZIP을 다운로드합니다.
2. ZIP 파일을 원하는 폴더에 완전히 압축 해제합니다.
3. `ScreenAlarm.exe`를 실행합니다.

.NET 런타임이 포함되어 있으므로 별도의 프로그램을 설치할 필요가 없습니다.

## 주요 기능

- 항상 다른 창 위에 표시되는 GIF 시계 위젯
- 알람까지 남은 시간을 분 단위로 표시
- 매일 반복 또는 특정 날짜의 일회성 알람
- 저작권 걱정 없는 내장 시계와 사용자 GIF·말풍선 PNG 선택
- 평소 반복 사운드와 1회 재생 알람 사운드 지원
- GIF 재생 속도 조절
- GIF, 말풍선, 텍스트 위치와 크기 조절
- 모든 배치와 설정 자동 저장
- 작업 표시줄 알림 영역에서 표시·종료 제어

## 빠른 사용법

1. 화면에 표시된 GIF를 마우스 오른쪽 버튼으로 클릭합니다.
2. 알람 시간과 날짜를 설정합니다.
3. `카운트다운 알람 사용`을 켭니다.
4. GIF와 사운드를 바꾸려면 `리소스 설정...`을 선택합니다.

별도 GIF를 선택하지 않아도 프로그램에 내장된 기본 시계가 표시됩니다.

GIF를 좌클릭 드래그하면 위젯 전체를 옮길 수 있습니다. 말풍선과 텍스트는 각각
드래그해서 배치할 수 있으며, `크기 조절 마크 표시`를 켜면 각 요소의 크기를 바꿀 수
있습니다.

## 알람 동작

- 평소에는 GIF와 카운트다운이 계속 표시됩니다.
- 알람 시간이 되면 지정한 알람 GIF로 바뀌고 알람 사운드가 한 번 재생됩니다.
- `알람 중지`를 누르면 평소 GIF와 반복 사운드로 돌아갑니다.
- 알람 GIF와 사운드를 모두 비우면 평소 GIF가 3배속으로 재생됩니다.
