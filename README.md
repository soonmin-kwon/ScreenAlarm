# Screen Alarm

프로그램을 실행하면 기본 GIF를 화면 오른쪽 위에 작은 창으로 표시하는 Windows 알람입니다.
GIF 창은 다른 프로그램보다 위에 유지되며 좌클릭 드래그로 옮길 수 있습니다.

실행 파일과 같은 폴더에 `default.gif`를 두면 최초 실행 시 자동으로 사용합니다.

## 실행

```powershell
dotnet run
```

별도의 설정창은 없습니다. 실행하면 GIF와 알람 시각까지 남은 시간이 바로 표시됩니다.
카운트다운은 초를 제외하고 `2시간 14분 남음`처럼 GIF 위에 직접 표시됩니다.
GIF를 우클릭하면 메뉴 안에서 알람 시간 설정, GIF 변경, 카운트다운 알람 사용 여부,
알람 화면 끄기, 프로그램 종료를 모두 조작할 수 있습니다.
날짜 지정은 선택 사항입니다. 날짜를 지정하면 해당 날짜와 시간에 한 번만 울리고,
날짜를 지정하지 않으면 매일 같은 시간에 반복됩니다.
알람 전용 GIF와 WAV/MP3/WMA 사운드를 별도로 선택할 수 있으며 알람 중지 시
원래 시계 GIF로 돌아옵니다. 두 알람 미디어가 모두 비어 있으면 말풍선과 텍스트를
숨긴 채 평소 GIF를 3배속으로 재생해 알람 시각 도달을 표시합니다.
리소스 설정에서 평소 사운드를 선택하면 프로그램 실행 중 반복 재생됩니다.
알람이 시작되면 평소 사운드는 멈추고 알람 사운드는 한 번만 재생되며,
알람 중지 후 평소 사운드가 다시 반복됩니다.
시간과 분은 별도 입력칸이며 `Tab`으로 시 입력칸에서 분 입력칸으로 이동합니다.
우클릭 메뉴에서 GIF 재생 속도를 0.1배부터 5배까지 숫자로 직접 입력할 수 있습니다.
창 오른쪽 아래 모서리를 좌클릭 드래그하면 크기가 조절되고, 나머지 영역을
좌클릭 드래그하면 위치가 이동합니다. 재생 속도와 크기는 다음 실행에도 유지됩니다.
GIF 창은 `Esc`로도 닫을 수 있습니다.

GIF 화면을 닫은 뒤에는 작업 표시줄 알림 영역의 Screen Alarm 아이콘을 더블클릭하거나
우클릭 후 `GIF 표시`를 선택해 다시 열 수 있습니다. 프로그램을 완전히 끝내려면
GIF 또는 알림 영역 아이콘을 우클릭하고 `프로그램 종료`를 선택합니다.

## 배포 파일 만들기

```powershell
dotnet publish -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true
```

생성 파일은 `bin\Release\net10.0-windows\win-x64\publish\ScreenAlarm.exe`에 있습니다.
